# 脚本导航14版修改说明

## 修改目标

根据您的要求，本次修改实现了以下功能：

1. **隐藏cmd窗口**：调用IDLE时不再弹出两个黑色的cmd窗口
2. **复用IDLE窗口**：多次运行会使用同一个IDLE窗口，保留之前的变量和运行记录
3. **自动导入函数**：打开脚本时，会自动将脚本中的所有函数和类导入到IDLE的交互环境中

## 修改内容

### 1. 修改 `脚本导航14版.py` 中的 `run_in_idle()` 函数

**原来的实现问题**：
- 使用 `cmd /c start` 启动，会弹出cmd窗口
- 使用 `.bat` 批处理文件启动IDLE
- 每次运行都会终止之前的IDLE进程，启动新进程

**修改后的实现**：
- 直接使用 Python 的 `subprocess.Popen` 启动IDLE
- 使用 `CREATE_NO_WINDOW` 标志隐藏窗口
- 检查IDLE进程是否存活，如果存活则复用
- 通过Socket发送脚本路径给IDLE，而不是重启进程

**关键代码**：
```python
# 使用 CREATE_NO_WINDOW 标志隐藏窗口
startupinfo = subprocess.STARTUPINFO()
startupinfo.dwFlags |= subprocess.STARTF_USESHOWWINDOW
startupinfo.wShowWindow = 0  # SW_HIDE
creationflags = subprocess.CREATE_NO_WINDOW

self._idle_proc = subprocess.Popen(
    cmd,
    startupinfo=startupinfo,
    creationflags=creationflags,
    cwd=str(SCRIPT_DIR)
)
```

### 2. 新增 `_send_script_to_idle()` 方法

**功能**：
- 通过Socket连接到IDLE的监听器
- 发送脚本路径，让IDLE加载脚本
- 包含重试机制，最多重试5次

**关键代码**：
```python
def _send_script_to_idle(self, script_path):
    """通过Socket发送脚本路径给IDLE"""
    with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as s:
        s.connect((HOST, PORT))
        message = f"RUN:{script_path}"
        s.sendall(message.encode('utf-8'))
```

### 3. 修改 `IDLE_bootstrap.py`

**原来的实现**：
- 使用 `exec()` 执行脚本代码
- 脚本中的变量会保留，但函数不能直接访问

**修改后的实现**：
- 使用 `importlib` 动态导入脚本作为模块
- 遍历模块的所有成员，将函数和类导入到全局命名空间
- 保留之前定义的变量

**关键代码**：
```python
def import_script_functions(script_path, global_namespace):
    """动态导入脚本中的所有函数、类到全局命名空间"""
    spec = importlib.util.spec_from_file_location(module_name, script_path)
    module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(module)

    # 导入所有函数、类到全局命名空间
    for name in dir(module):
        if name.startswith('_'):
            continue
        obj = getattr(module, name)
        if inspect.isfunction(obj) or inspect.isclass(obj):
            global_namespace[name] = obj
```

## 使用说明

### 1. 启动脚本导航

正常启动"脚本导航14版.py"，界面和之前完全一样。

### 2. 打开并运行脚本

1. 在脚本导航中打开一个Python脚本（例如 `test_script.py`）
2. 按 `Ctrl+F5` 运行脚本
3. **首次运行**：
   - IDLE窗口会启动（不会弹出黑色cmd窗口）
   - 脚本中的所有函数和类会自动导入
   - 显示导入的函数列表

4. **再次运行**（同一个或不同的脚本）：
   - 不会启动新的IDLE窗口
   - 使用已打开的IDLE窗口
   - 新脚本的函数会追加导入
   - **之前定义的变量仍然保留**

### 3. 在IDLE中使用

在IDLE的交互环境中，您可以：

```python
# 查看所有可用的对象
>>> dir()

# 查看某个函数的帮助
>>> help(function_name)

# 直接调用脚本中的函数
>>> result = my_function(arg1, arg2)

# 使用之前运行时定义的变量
>>> print(previous_variable)

# 重新导入模块查看更新（如果修改了脚本）
>>> import importlib
>>> importlib.reload(module_name)
```

## 注意事项

1. **首次运行需要等待**：IDLE启动需要2秒左右，请耐心等待
2. **端口冲突**：如果提示端口被占用，说明之前的IDLE没有正常关闭，请手动结束进程
3. **函数重名**：如果多个脚本有同名函数，后导入的会覆盖先前的
4. **模块级代码**：脚本中模块级别的代码（不在函数中的代码）会在导入时执行一次

## 技术细节

### 隐藏窗口的实现

Windows下启动子进程有三种方式：
1. 正常启动（会显示窗口）
2. 使用 `CREATE_NO_WINDOW` 标志（不显示窗口）
3. 使用 `pythonw.exe`（专门用于GUI程序）

本次修改使用方法2，确保完全隐藏cmd窗口。

### Socket通信协议

- **监听端口**：127.0.0.1:65432
- **消息格式**：`RUN:脚本路径`
- **超时设置**：2秒
- **重试机制**：最多5次

### 动态导入机制

使用 `importlib.util.spec_from_file_location` 可以：
- 从任意路径加载Python文件为模块
- 不需要在 `sys.path` 中
- 可以重复加载不同名称的模块
- 支持热重载

## 常见问题

### Q1：按Ctrl+F5后没有反应

**可能原因**：
- IDLE启动较慢，请等待2-3秒
- 端口被占用，检查任务管理器中是否有残留的python进程

**解决方法**：
```bash
# 查看端口占用
netstat -ano | findstr 65432

# 结束占用端口的进程
taskkill /F /PID <进程ID>
```

### Q2：IDLE窗口一闪而过

**可能原因**：
- `IDLE_bootstrap.py` 文件不存在或路径不对

**解决方法**：
- 检查文件路径：`D:/gemini-tasks/cad/scripts/IDLE_bootstrap.py`
- 确保文件存在且内容正确

### Q3：函数没有自动导入

**可能原因**：
- 函数名以下划线开头（私有函数不会导入）
- Socket连接失败

**解决方法**：
- 查看IDLE窗口的输出信息
- 检查是否显示"✓ 已导入 X 个对象"

### Q4：想要执行脚本而不是导入

**解决方法**：
在 `IDLE_bootstrap.py` 中，取消注释以下代码：
```python
# 方案2：如果需要执行脚本（取消注释下面的代码）
with open(script_path, 'r', encoding='utf-8') as f:
    code = f.read()
exec(code, global_vars)
```

同时注释掉方案1的代码。
