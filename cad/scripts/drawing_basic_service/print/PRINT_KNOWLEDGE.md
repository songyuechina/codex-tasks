# PRINT_KNOWLEDGE.md

## 1. 打印区域认知

打印任务首先不是“点打印”，而是“找到正确打印区域”。

当前区域识别规则：

- `basic`
  严格容差命中 288 标准打印区域。
- `adaptive`
  对落在允许范围内的矩形多段线做标准图幅适配。
- `purified_adaptive`
  对 `adaptive` 结果进一步做内容净化。

## 2. 伪打印区域问题

适配模式会引入伪区域。

当前真实案例已经证明：

- `adaptive = 49`
- `purified_adaptive = 47`

被净化掉的伪区域句柄：

- `7A9B`
- `CE6F`

这说明：

- 适配能力有价值
- 但不能直接信任所有适配结果

新的异常电气案例进一步证明：

- 有些文件会在真实图纸群外围再包一个极大的矩形多段线
- 单靠 `content_analysis` 去掉局部伪区域仍不够
- 需要再分析“伪极大打印范围”

当前新增经验是：

- 如果文件同时出现伪极大范围和净化适配需要清除的伪区域
- 则可将最大伪极大范围视为用户真实要打印的总范围
- 只保留该范围内部的打印区域，再继续净化

## 3. 打印信息分析问题

打印信息分析不是打印模式，而是辅助分析。

分析对象是指定打印区域。

每个打印区域当前需要回答：

1. 是否有内框线
2. 是否有合乎要求的右下角图签块
3. 图签块是属性块还是普通块
4. 若是属性块，标签和值是什么
5. 若是普通块，其外包盒内有哪些 CAD / 天正文字
6. 哪些文字属于图纸名称
7. 哪些文字属于图号
8. 是否已拿到项目名称

## 4. 当前文字分类经验

当前规则是经验性规则，不是最终答案：

- 含中文，优先视作图纸名称候选
- 不含中文且包含字母或数字，优先视作图号候选
- 纯标点不应视作图号

这套规则目前能覆盖大部分普通图签块，但未来可能被新案例修正。

## 5. 当前图签分析经验

当前复杂案例中：

- 内框线可稳定命中
- 右下角图签块可稳定命中
- 主图签块大多表现为普通块 `TQ1`
- 因此普通块外包盒取文是当前有效主路径

## 6. 当前边界

打印信息分析当前仍是辅助链。

它不会自动替代：

- PDF 命名策略
- 目录编排
- 图签回填

但它已经为这些后续能力准备了区域级结构化信息。

## 7. 当前高频风险

- COM busy / rejected
- 适配模式引入伪区域
- 伪极大外包矩形把整组图纸再次错误包围
- 普通块内正文污染文字干扰标题判断
- 图号被标点或噪声误判
- 项目名称长期缺失
- 批量打印时 WPS PDF 窗口持续堆积

因此，后续迭代应优先围绕：

- 稳定性
- 去噪
- 准确率
- 结果可复查性

## 8. 当前 WPS 处理经验

现实打印链中，WPS PDF 窗口可能在批量打印时持续弹出并堆积。

当前有效经验：

- 默认每成功 `6` 张后执行一次 WPS 清理
- 横向批次和竖向批次切换前后再执行强制清理
- 清理策略先枚举可见 WPS 窗口，逐句柄执行 `SW_RESTORE / SW_MAXIMIZE / WM_CLOSE`
- 只要本轮观察到过 WPS 窗口，就继续按窗口 PID 执行 `taskkill /F /PID <pid> /T`
- 之后固定再做一次 `taskkill /F /IM wps.exe /T` 与 `taskkill /F /IM wpspdf.exe /T`，避免只关窗但进程未退出、窗口随后又回弹

若未来能稳定实现“完全不弹出 WPS 窗口”，可以替代上述策略；在此之前，强制清理仍是权威保底方案
