# Move

## 基本信息
- kind: `method`
- owners: `All Drawing Objects`
- pywin32: `object.Move(point1, point2)`

## 作用
按两个 3D 点定义位移，是最基础的空间对位方法之一。

## 高频场景
- 对象平移到目标位置
- 在变换链前做简单位移
- 调整空间放置关系
