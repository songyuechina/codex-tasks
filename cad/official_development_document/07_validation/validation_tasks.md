# Validation Tasks

本体系至少应支持以下问题在不重翻 CHM 的情况下快速定位：

1. 如何获取当前活动文档
2. 如何枚举所有布局
3. 如何切换到指定布局
4. 如何构造选择集并遍历对象
5. 如何读取块属性
6. 如何插入块或插入 DWG
7. 如何读取布局打印信息
8. 如何通过 `SendCommand` 做回退
9. 如何把图名/目录信息写回图签
10. 如何从 Excel 生成目录或更新目录图签

## 验收口径

- 能先命中 `task_id` 或精确入口字段
- 任务卡能回落到 `symbol / owner / project_function / module_path`
- 核心符号能指向 pywin32 规则
- 中文查询即使可用，也只能作为辅助 alias，不是主成功标准
- 真正的成功标准是 Codex 能快速落到项目内稳定实现路径
