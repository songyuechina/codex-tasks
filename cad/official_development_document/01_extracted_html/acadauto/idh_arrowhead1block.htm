Arrowhead1Block Property

Specifies the block to use as the custom arrowhead for the first end of the dimension line.

See Also | Example

Signature

object.Arrowhead1Block

object

Dim3PointAngular, DimAligned, DimAngular, DimArcLength, DimDiametric, DimRotated
The objects this property applies to.

Arrowhead1Block

String; read-write
The name of the block to use as the arrowhead for the first end of the dimension line.

System variables

This property overrides the value of the DIMBLK1 system variable for the given dimension.
