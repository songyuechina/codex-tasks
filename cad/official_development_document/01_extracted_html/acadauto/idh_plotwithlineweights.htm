PlotWithLineweights Property

Specifies whether objects plot with the lineweights they're assigned in the plot file, or with the lineweights in the drawing file.

See Also | Example

Signature

object.PlotWithLineweights

object

Layout, PlotConfiguration
The objects this property applies to.

PlotWithLineweights

Boolean; read-write

TRUE: Plot using the lineweights in the plot style.

FALSE: Plot using the lineweights in the drawing file.
