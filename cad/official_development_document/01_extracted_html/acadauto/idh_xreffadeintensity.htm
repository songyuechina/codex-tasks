XRefFadeIntensity Property

Controls the dimming intensity for XRefs.

See Also | Example

Signature

object.XRefFadeIntensity

object

PreferencesDisplay
The object this property applies to.

XRefFadeIntensity

Long; read-write
A positive long integer from 1 to 90 representing the percentage of fade for XRefs.

System variables

The value of this property is stored in the XFADECTL system variable.

Remarks

The initial value for this property is 50.
