FileDependencies Collection

Creates, updates, retrieves, and removes items in the File Dependency List.

VBA class name:

AcadFileDependencies 

Create using:

N/A 

Access via:

Document.FileDependencies 

Files in the AutoCAD 2004 drawing-file format contain a File Dependency List. The File Dependency List is a list of the files on which the drawing file depends. You can perform operations on the File Dependency List using the FileDependencies collection.
