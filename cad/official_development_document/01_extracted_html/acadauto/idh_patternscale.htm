PatternScale Property

Specifies the hatch pattern scale.

See Also | Example

Signature

object.PatternScale

object

Hatch
The object this property applies to.

PatternScale

Double; read-write
Must be non-zero.

System variables

The value of this property is stored in the HPSCALE system variable.

Remarks

If the PatternType property is set to acHatchPatternTypeUserDefined, then PatternScale is not used.
