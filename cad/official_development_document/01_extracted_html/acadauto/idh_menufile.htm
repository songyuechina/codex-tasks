MenuFile Property

Specifies the location of the AutoCAD customization file for the session.

See Also | Example

Signature

object.MenuFile

object

PreferencesFiles
The object this property applies to.

MenuFile

String; read-write
The location of the AutoCAD customization file.

Remarks

This property contains the drive, path, and file name for a customization (CUI) file.
