ExtensionLineExtend Property

Specifies the distance the extension line extends beyond the dimension line.

See Also | Example

Signature

object.ExtensionLineExtend

object

Dim3PointAngular, DimAligned, DimAngular, DimArcLength, DimRotated
The objects this property applies to.

ExtensionLineExtend

Double; read-write
A positive real number specifying the distance to extend the extension line beyond the dimension line.

System variables

This property overrides the value of the DIMEXE system variable for the given dimension.

Remarks

The initial value for this property is 0.1800.
