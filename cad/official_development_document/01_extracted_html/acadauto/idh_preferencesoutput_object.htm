PreferencesOutput object

This object contains the options from the Output tab on the Options dialog.

VBA class name:

AcadPreferencesOutput 

Create using:

N/A 

Access via:

Application.Preferences.Output 

This object holds all the options from the Output tab on the Options dialog stored in the registry. All options that are stored with the drawing can be found on the DatabasePreferences object.
