SetBlockTableRecordId32 Method

For a 64-Bit system, sets a cell's block table record id.

See Also | Example

Signature

object.SetBlockTableRecordId32 nRow, nCol, nContent, blkId, autoFit

Object

Table
The object this method applies to.

nRow

Integer; Input-only
The index of the column.

nCol

Integer; Input-only
The index of the column.

nContent

Integer; Input-only
The value of the content.

blkId

Long; Input-only
The new block table record.

autoFit

VARIANT_BOOL; Input-only
The flag indicating whether to auto fit the block Integero the specified cell.
