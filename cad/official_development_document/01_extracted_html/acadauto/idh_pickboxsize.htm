PickBoxSize Property

Specifies the size of the object selection target.

See Also | Example

Signature

object.PickBoxSize

object

PreferencesSelection
The object this property applies to.

PickBoxSize

Long; read-write
The height of the object selection target in pixels. You can enter a value from 0 to 50.

System variables

The value for this property is stored in the PICKBOX system variable.

Remarks

The initial value of this property is 3.
