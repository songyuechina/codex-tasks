SetProjectFilePath Method

Sets the directory in which AutoCAD looks for external reference files.

See Also | Example

Signature

object.SetProjectFilePath ProjectName, ProjectFilePath

Object

PreferencesFiles
The object this method applies to.

ProjectName

String; input-only
The name of the project. This name is also controlled by the PROJECTNAME system variable.

ProjectFilePath

String; input-only
The directory in which AutoCAD looks for external reference files.
