AltUnits Property

Enables dimensioning in alternate units.

See Also | Example

Signature

object.AltUnits

object

DimAligned, DimArcLength, DimDiametric, DimOrdinate, DimRadial, DimRadialLarge, DimRotated
The objects this property applies to.

AltUnits

Boolean; read-write

TRUE: Enable dimensioning in alternate units.

FALSE: Disable dimensioning in alternate units.

System variables

This property overrides the value of the DIMALT system variable for the given dimension.
