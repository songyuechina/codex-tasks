RemoveHiddenLines Property

Specifies if hidden lines are to be plotted on a paper space viewport.

See Also | Example

Signature

object.RemoveHiddenLines

object

PViewport
The object this property applies to.

RemoveHiddenLines

Boolean; read-write

TRUE: Removes hidden lines in the plot.

FALSE: Does not remove hidden lines in the plot.

Remarks

This property is obsolete and will be removed in a future version.
