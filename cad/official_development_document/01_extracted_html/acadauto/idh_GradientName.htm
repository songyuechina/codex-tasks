GradientName Property

Specifies the pattern name of the gradient.

See Also | Example

Signature

object.GradientName

object

Hatch
The object this property applies to.

GradientName

String; read-write
The pattern name of the gradient, which can be LINEAR, CYLINDER, INVCYLINDER, SPHERICAL HEMISPHERICAL, CURVED, INVSPHERICAL, INVHEMISPHERICAL, or INVCURVED.
