SetBlockAttributeValue32 Method

For a 64-Bit system, sets the attribute value in block content with attribute definition id.

See Also | Example

Signature

object.SetBlockAttributeValue32 attdefId, value

Object

MLeader
The object this method applies to.

attdefID

Long; Input-only
The attribute definition ID.

value

String; Input-only
The new attribute value.
