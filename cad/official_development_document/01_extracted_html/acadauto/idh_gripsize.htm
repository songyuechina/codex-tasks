GripSize Property

Specifies the size of grips.

See Also | Example

Signature

object.GripSize

object

PreferencesSelection
The object this property applies to.

GripSize

Long; read-write
The size of the box drawn to display the grip, in pixels. The practical range for this property is 1 to 20, although any value from 1 to 255 is legal.

System variables

The value for this property is stored in the GRIPSIZE system variable.

Remarks

The initial value of this property is 3.
