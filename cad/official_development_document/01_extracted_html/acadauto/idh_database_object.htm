Database object

The contents of an XRef block.

VBA class name:

AcadDatabase 

Create using:

Not applicable 

Access via:

Block.XRefDatabase 

This object provides access to the contents of an external reference block. It is only available on blocks whose IsXRef property is equal to TRUE.
