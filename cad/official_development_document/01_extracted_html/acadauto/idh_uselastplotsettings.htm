UseLastPlotSettings Property

Applies the plotting settings of the last successful plot.

See Also | Example

Signature

object.UseLastPlotSettings

object

PreferencesOutput
The object this property applies to.

UseLastPlotSettings

Boolean; read-write

TRUE: Use the settings of the last successful plot as the current plot settings.

FALSE: Do not use the settings of the last successful plot as the current plot settings.
