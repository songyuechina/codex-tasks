Parent Property

Gets the parent of the object.

See Also | Example

Signature

object.Parent

object

MenuBar , MenuGroup,, MenuGroups, PopupMenu, PopupMenus, PopupMenuItem, Toolbar, Toolbars, ToolbarItem
The objects this property applies to.

Parent

The parent of the object; read-only
This user-specified variable must be declared as an appropriate object type. The valid object types are: Application, MenuBar, MenuGroup, MenuGroups, PopupMenu, PopupMenus, Toolbar, Toolbars
