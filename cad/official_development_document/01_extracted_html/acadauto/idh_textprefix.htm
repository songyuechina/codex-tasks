TextPrefix Property

Specifies the dimension value prefix.

See Also | Example

Signature

object.TextPrefix

object

Dim3PointAngular, DimAligned, DimAngular, DimArcLength, DimDiametric, DimOrdinate, DimRadial, DimRadialLarge, DimRotated
The object this property applies to.

TextPrefix

String; read-write
The prefix for the dimension value.

System variables

This property overrides the value of the DIMPOST system variable for the given dimension.

Remarks

The initial value for this property is "".
