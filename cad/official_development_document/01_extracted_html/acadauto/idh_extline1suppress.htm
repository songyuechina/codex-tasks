ExtLine1Suppress Property

Specifies the suppression of the first extension line.

See Also | Example

Signature

object.ExtLine1Suppress

object

Dim3PointAngular, DimAligned, DimAngular, DimArcLength, DimRotated
The objects this property applies to.

ExtLine1Suppress

Boolean; read-write

TRUE: Suppress the first extension line.

FALSE: Do not suppress the first extension line.

System variables

This property overrides the value of the DIMSE1 system variable for the given dimension.

Remarks

The initial value for this property is FALSE.
