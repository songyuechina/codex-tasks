LayoutShowPlotSetup Property

Toggles the display of the Plot Setup dialog when a new layout is created.

See Also | Example

Signature

object.LayoutShowPlotSetup

object

PreferencesDisplay
The object this property applies to.

LayoutShowPlotSetup

Boolean; read-write

TRUE: The dialog is displayed when a new layout is created.

FALSE: The dialog is not displayed when a new layout is created.

Remarks

The initial value for this property is TRUE.
