AutoSnapToolTip Property

Toggles the AutoSnap tooltips.

See Also | Example

Signature

object.AutoSnapToolTip

object

PreferencesDrafting
The object this property applies to.

AutoSnapToolTip

Boolean; read-write

TRUE: Enables the AutoSnap tooltips.

FALSE: Disables the AutoSnap tooltips.

System variables

The value of this property is stored in the AUTOSNAP system variable.

Remarks

The initial value for this property is TRUE.
