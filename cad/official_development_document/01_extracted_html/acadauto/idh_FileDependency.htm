FileDependency object

Provides information about entries in the File Dependency List of a drawing file.

VBA class name:

AcadFileDependency 

Create using:

FileDependencies.CreateEntry 

Access via:

FileDependencies.Item 

The FileDependency object describes an entry in the File Dependency List. The files on which a drawing file depends are in its File Dependency List.
