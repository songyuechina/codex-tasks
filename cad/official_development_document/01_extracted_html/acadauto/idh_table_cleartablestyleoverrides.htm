ClearTableStyleOverrides Method

Clears table style overrides.

See Also | Example

Signature

object.ClearTableStyleOverrides(flag)

Object

Table
The object this method applies to.

flag

Long; one of three integer values

0

Deletes all table and cell overrides.

1

Deletes all table overrides, but retains cell overrides.

2

Deletes all cell overrides, but retains table overrides.
