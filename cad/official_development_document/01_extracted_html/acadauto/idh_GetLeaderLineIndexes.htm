GetLeaderLineIndexes Method

Gets the indexes of leaderlines of the specific leader.

See Also | Example

Signature

RetVal = object.GetLeaderLineIndexes(leaderIndex)

Object

MLeader
The object this method applies to.

leaderIndex

Long; input-only
The leader line index.

RetVal

Variant (three-element array of doubles)
The indexes of leaderlines owned by the input leader.
