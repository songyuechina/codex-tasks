ArrowheadBlock Property

Specifies the block to use as the custom arrowhead for a radial dimension or leader line.

See Also | Example

Signature

object.ArrowheadBlock

object

DimRadial, DimRadialLarge, Leader, MLeader
The objects this property applies to.

ArrowheadBlock

String; read-write
The name of the block to use as the arrowhead for the leader.

System variables

This property overrides the value of the DIMLDRBLK system variable for the given dimension.
