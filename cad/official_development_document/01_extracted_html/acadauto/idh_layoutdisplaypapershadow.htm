LayoutDisplayPaperShadow Property

Toggles the display of the paper background shadow in layouts.

See Also | Example

Signature

object.LayoutDisplayPaperShadow

object

PreferencesDisplay
The object this property applies to.

LayoutDisplayPaperShadow

Boolean; read-write

TRUE: The shadow is displayed in layouts.

FALSE: The shadow is not displayed in layouts.

Remarks

The initial value for this property is TRUE.
