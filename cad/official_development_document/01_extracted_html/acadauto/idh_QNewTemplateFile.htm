QNewTemplateFile Property

Sets the default template file name for the QNEW command.

See Also | Example

Signature

object.QNewTemplateFile

Object

PreferencesFiles
The object this property applies to.

QNewTemplateFile

String; read-write

Remarks

The value of this property controls the default template used with the QNEW command. To use this property, you must declare an object as an AcadPrefrencesFiles object.
