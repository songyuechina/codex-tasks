MLeaderStyle object

Adds, modifies, and deletes MLeader styles.

VBA class name:

AcadMLeaderStyle 

Create using:

Dim customObj as AcadMLeaderStyle

Access via:

Dim customObj as AcadMLeaderStyle

You can use the MLeaderStyle object to store MLeader formatting. The object controls the initial formatting of a newly created MLeader object.

You can see an implementation of the MLeaderStyle object by following this example.
