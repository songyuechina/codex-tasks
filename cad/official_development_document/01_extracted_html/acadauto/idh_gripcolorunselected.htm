GripColorUnselected Property

Specifies the color of unselected grips.

See Also | Example

Signature

object.GripColorUnselected

object

PreferencesSelection
The object this property applies to.

GripColorUnselected

acColor enum; read-write
Control of the selected grips (drawn as box outlines). The valid range is 1 to 255, or one of the constants listed here:

acRed

acYellow

acGreen

acCyan

acBlue

acMagenta

acWhite

System variables

The value for this property is stored in the GRIPCOLOR system variable.

Remarks

The initial value of this property is acBlue.
