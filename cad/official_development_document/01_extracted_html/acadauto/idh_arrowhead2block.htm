Arrowhead2Block Property

Specifies the block to use as the custom arrowhead for the second end of the dimension line.

See Also | Example

Signature

object.Arrowhead2Block

object

Dim3PointAngular, DimAligned, DimAngular, DimArcLength, DimDiametric, DimRotated
The objects this property applies to.

Arrowhead2Block

String; read-write
The name of the block to use as the arrowhead for the first end of the dimension line.

System variables

This property overrides the value of the DIMBLK2 system variable for the given dimension.
