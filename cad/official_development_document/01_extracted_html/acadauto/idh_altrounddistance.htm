AltRoundDistance Property

Specifies the rounding of alternate units.

See Also | Example

Signature

object.AltRoundDistance

object

DimAligned, DimArcLength, DimDiametric, DimOrdinate, DimRadial, DimRadialLarge, DimRotated
The objects this property applies to.

AltRoundDistance

Double; read-write
A positive real number representing the value to round distances to. The initial value is 0.00.

System variables

This property overrides the value of the DIMALTRND system variable for the given dimension.

Remarks

If the AltUnits property is turned on, this property defines the number to round distances to.
