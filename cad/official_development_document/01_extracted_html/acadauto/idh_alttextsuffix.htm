AltTextSuffix Property

Specifies a suffix for the alternate dimension measurement for all dimension types except angular.

See Also | Example

Signature

object.AltTextSuffix

object

DimAligned, DimArcLength, DimDiametric, DimOrdinate, DimRadial, DimRadialLarge, DimRotated
The objects this property applies to.

AltTextSuffix

String; read-write
The suffix for the alternate dimensions.

System variables

This property overrides the value of the DIMAPOST system variable for the given dimension.

Remarks

The initial value for this property is "".

To turn off an established suffix, set this property equal to a single period (.).
