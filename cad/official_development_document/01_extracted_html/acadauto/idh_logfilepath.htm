LogFilePath Property

Specifies the location for the log file.

See Also | Example

Signature

object.LogFilePath

object

PreferencesFiles
The object this property applies to.

LogFilePath

String; read-write
The drive and path for the log file.

System variables

The value for this property is stored in the LOGFILEPATH system variable.

Remarks

Use the LogFileOn property to enable or disable log file capabilities.
