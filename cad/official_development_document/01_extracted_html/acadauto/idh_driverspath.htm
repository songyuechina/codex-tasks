DriversPath Property

Specifies the directory in which AutoCAD looks for ADI device drivers for the video display, pointing devices, printers, and plotters.

See Also | Example

Signature

object.DriversPath

object

PreferencesFiles
The object this property applies to.

DriversPath

String; read-write
The directory in which the device drivers are located. Specify a drive letter and path for each path. Separate multiple directory listings with a semicolon (;).
