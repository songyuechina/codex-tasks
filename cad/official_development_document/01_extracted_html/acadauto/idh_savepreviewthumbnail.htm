SavePreviewThumbnail Property

Specifies if BMP preview images are saved with the drawing.

See Also | Example

Signature

object.SavePreviewThumbnail

object

PreferencesOpenSave
The object this property applies to.

SavePreviewThumbnail

Boolean; read-write

TRUE: No preview image is created.

FALSE: Preview image is created.

System variables

The value for this property is saved in the RASTERPREVIEW system variable.

Remarks

The initial value for this property is TRUE.
