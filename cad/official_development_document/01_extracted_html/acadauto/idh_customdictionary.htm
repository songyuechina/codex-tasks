CustomDictionary Property

Specifies a custom dictionary to use if you have one.

See Also | Example

Signature

object.CustomDictionary

object

PreferencesFiles
The object this property applies to.

CustomDictionary

String; read-write
The custom dictionary to use.

Remarks

This property contains the drive, path, and file name of the custom dictionary for the AutoCAD session.
