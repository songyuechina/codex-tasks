About Overlaying Xrefs (VBA/ActiveX)

 
 
 

Overlaying is similar to attaching, except when a drawing is attached or overlaid.

Any other overlays nested in it are ignored and, therefore, not displayed. In other words, nested overlays are not read in.

To overlay an xref, set the Overlay parameter of the AttachExternalReference method to TRUE.
