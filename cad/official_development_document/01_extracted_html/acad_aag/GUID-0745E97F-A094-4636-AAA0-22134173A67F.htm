About Handling Object Level Events (VBA/ActiveX)

 
 
 

The object level event is not persistent in AutoCAD VBA. That is, it is not automatically enabled when a VBA project is loaded.

An object level event must be enabled for VBA and all other ActiveX Automation controllers.

Once the object level events is enabled, the Modified event is available to you. This event is triggered when an object in the drawing has been modified.
