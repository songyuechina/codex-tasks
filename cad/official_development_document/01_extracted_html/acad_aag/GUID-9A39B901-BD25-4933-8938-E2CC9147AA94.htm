To Set the AutoCAD VBA Project Options (VBA/ActiveX)

 
 
 

Some of the AutoCAD VBA settings restrict the loading of project files and execution of macros.

  1. On the ribbon, click Manage tab Applications panel Run VBA Macro.
  2. In the Macros dialog box, click Options.
  3. In the Options dialog box, enable or clear the options in the dialog box based on your preferences and the security you want to provide. Click OK.
