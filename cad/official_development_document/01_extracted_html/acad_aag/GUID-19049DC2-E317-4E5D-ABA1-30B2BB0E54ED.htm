To Open the VBA IDE on Demand (VBA/ActiveX)

 
 
 

The VBA IDE can be opened when a project file is first loaded, or when you want to create or edit a project file that has already been loaded.

Do one of the following:

  • On the ribbon, click Manage tab Applications panel Visual Basic Editor.
  • At the AutoCAD Command prompt, enter vbaide.
