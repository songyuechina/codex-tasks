About Database Preferences (VBA/ActiveX)

 
 
 

In addition to the nine Preferences objects, the DatabasePreferences object contains all the options stored in the drawing.

This separate object was provided to make the drawing-stored options available to applications accessing AutoCAD drawings without first starting the AutoCAD application (ObjectDBX applications).

The DatabasePreferences object is found under the Document object.
