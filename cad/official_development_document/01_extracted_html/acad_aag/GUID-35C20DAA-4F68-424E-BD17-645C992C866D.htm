To Save a Project Using the VBA Manager (VBA/ActiveX)

 
 
 

Changes made to a VBA project must be saved before it can be unloaded.

  1. On the ribbon, click Manage tab Applications panel (expanded) VBA Manager.
  2. In the VBA Manager, select a project to save.
  3. Click Save As.
  4. In the Save As dialog box, enter a name and specify a location for the VBA project file. Click Save.
