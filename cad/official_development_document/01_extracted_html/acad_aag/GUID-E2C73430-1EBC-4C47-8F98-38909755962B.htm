About Using TrueType Fonts (VBA/ActiveX)

 
 
 

TrueType fonts always appear filled in your drawing; however, when you plot, the AutoCAD TEXTFILL system variable controls whether the fonts are filled.

By default TEXTFILL is set to 1 to plot the filled-in fonts. When you export the drawing to PostScript® format with the Export method and print it on a PostScript device, the font is plotted as designed.
