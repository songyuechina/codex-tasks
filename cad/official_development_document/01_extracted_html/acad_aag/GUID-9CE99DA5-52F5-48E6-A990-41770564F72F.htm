To Change the Name of a Project (VBA/ActiveX)

 
 
 

You can rename a project from the VBA IDE.

  1. In the VBA IDE, Project Explorer window, select the project to change.
  2. Right-click the project and click <project_name> Properties.
  3. In the <project_name> - Project Properties dialog box, in the Project Name text box, edit the project's name. Click OK.
