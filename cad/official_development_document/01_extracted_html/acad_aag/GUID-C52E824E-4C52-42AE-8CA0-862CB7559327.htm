About Adding Separators to a Toolbar (VBA/ActiveX)

 
 
 

To add a separator to a toolbar, use the AddSeparator method. This method creates a new ToolbarItem object and adds it to the designated toolbar.

This kind of ToolbarItem object is assigned the type of acSeparator. The type of a Toolbar button can be found through the Type property.

The AddSeparator method takes one parameter as input: Index. The Index parameter is an integer that specifies the position of the separator within the toolbar. The index begins with position zero (0) as the first position on the toolbar after the title.
