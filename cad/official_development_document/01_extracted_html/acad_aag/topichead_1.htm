Getting Started with VBA

 
 
 

Topics in this section

  • About Embedded and Global VBA Projects (VBA/ActiveX)

    An AutoCAD VBA project is a collection of code modules, class modules, and forms that work together to perform a given function. Projects can be stored within an AutoCAD drawing, or as a separate file.

  • About Organizing Your Projects with the VBA Manager (ActiveX)

    You can view all the VBA projects loaded in the current AutoCAD session by using the VBA Manager. It is an AutoCAD tool that allows you to load, unload, save, create, embed, and extract VBA projects.

  • About Handling Your Macros (VBA/ActiveX)

    A macro is a public (executable) subroutine. Each project usually contains at least one macro.

  • About Editing Your Projects with the VBA IDE (VBA/ActiveX)

    Once a project has been loaded into AutoCAD, you can edit the code, forms, and references for that project using the VBA interactive development environment.

  • Exercise: An Introduction to VBA (VBA/ActiveX)

    In this exercise you will create a new AutoCAD drawing, add a line of text to that drawing, then save the drawing, all from VBA.

  • About More Information on the VBA IDE (VBA/ActiveX)

    More information on the VBA IDE and the VBA programming language is available in the Help files provided by Microsoft.

  • AutoCAD VBA Project Terms Reference (VBA/ActiveX)

    Terms related to VBA projects and the VBA IDE.

  • AutoCAD VBA Commands Reference (VBA/ActiveX)

    Commands related to VBA projects and the VBA IDE.

  • AutoCAD VBA AutoLISP Functions Reference (VBA/ActiveX)

    AutoLISP functions related working with VBA projects.

  • To Add a New Component to a Project (VBA/ActiveX)

    New modules and user forms can be added to a VBA project file.
