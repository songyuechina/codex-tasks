About Using Variants in Methods and Properties (VBA/ActiveX)

 
 
 

ActiveX Automation uses variants to pass arrays of data.

Although this may seem confusing to a novice user, it is not difficult once you learn the basics. In addition, AutoCAD ActiveX Automation provides utilities to help you convert your data types.

Topics in this section

  • About Variants (VBA/ActiveX)

    A variant is a special data type that can contain any kind of data except fixed-length string data and user-defined types.

  • About Using Variants for Array Data (VBA/ActiveX)

    Variants are used to pass array data in and out of AutoCAD ActiveX Automation.

  • About Converting Arrays to Variants (VBA/ActiveX)

    AutoCAD ActiveX Automation provides a utility method to convert an array of data into a variant.

  • About Interpreting Variant Arrays (VBA/ActiveX)

    Array information passed back from AutoCAD ActiveX Automation is passed back as a variant.
