About Using Geometric Tolerances (VBA/ActiveX)

 
 
 

Geometric tolerancing shows deviations of form, profile, orientation, location, and runout of a feature.

You add geometric tolerances in feature control frames. These frames contain all the tolerance information for a single dimension.

Topics in this section

    To create a geometric tolerance, use the AddTolerance method.

  • About Editing Tolerances (VBA/ActiveX)

    Geometric tolerances can be modified using the properties and methods associated with the object, or by changing the values of system variables before creating a Tolerance object.
