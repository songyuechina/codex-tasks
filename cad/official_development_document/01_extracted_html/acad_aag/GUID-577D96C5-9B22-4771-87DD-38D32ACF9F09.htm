About Clipping Blocks and Xrefs (VBA/ActiveX)

 
 
 

ActiveX Automation does not provide a method to clip the boundaries of blocks and xrefs, instead use the XCLIP command.

Use the XCLIP command at the AutoCAD Command prompt, or send the XCLIP command to AutoCAD using the SendCommand method.
