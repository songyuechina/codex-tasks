Customize Toolbars and Menus

 
 
 

Topics in this section

  • About the MenuBar and MenuGroups Collections (VBA/ActiveX)

    AutoCAD ActiveX provides several menu-related objects. The two most important are the MenuBar collection and the MenuGroups collection.

  • About Loading Menu Groups (VBA/ActiveX)

    Menu groups are loaded into AutoCAD using the Load method.

  • About Changing the Menu Bar (VBA/ActiveX)

    The menu bar can be completely replaced by a new menu group if that group is loaded as the base menu.

  • About Creating and Editing Pull-Down and Shortcut Menus (VBA/ActiveX)

    AutoCAD ActiveX/VBA has the ability to customize two types of AutoCAD menus: pull-down menus and shortcut menus (sometimes called cursor menus).

  • About Creating and Editing Toolbars (VBA/ActiveX)

    Using AutoCAD ActiveX/VBA you can create and edit toolbars within an existing menu group.

  • About Creating Macros (VBA/ActiveX)

    A macro is a series of commands that executes specific actions when a toolbar item is selected.

  • About Creating Status-Line Help for Menu Items and Toolbar Items (VBA/ActiveX)

    Status-line help messages are an important aspect of native help support. These are the simple, descriptive messages that appear in the status line when a menu or toolbar item is highlighted.

  • About Adding Entries to the Right-Click Menu (VBA/ActiveX)

    The right-click menu, or shortcut menu, is a special menu included in the AutoCAD base menu group. This menu appears when the user holds Shift and clicks the right mouse button.
