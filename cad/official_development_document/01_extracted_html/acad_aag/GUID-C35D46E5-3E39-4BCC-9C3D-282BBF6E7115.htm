To Unload a VBA Project (VBA/ActiveX)

 
 
 

VBA project files can be unloaded when they are no longer needed.

  1. On the ribbon, click Manage tab Applications panel (expanded) VBA Manager.
  2. In the VBA Manager, select the VBA project you want to unload.
  3. Click Unload.

You can also unload a project file using the VBAUNLOAD command.
