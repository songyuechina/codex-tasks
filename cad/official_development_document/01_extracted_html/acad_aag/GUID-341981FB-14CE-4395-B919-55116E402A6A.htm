About Working with Raster Images (VBA/ActiveX)

 
 
 

With AutoCAD®, you can add raster images to your vector-based AutoCAD drawings, and then view and plot the resulting file.

Topics in this section

  • About Attaching and Scaling a Raster Image (VBA/ActiveX)

    Images can be placed in a drawing file, but they are not actually part of the file. The image is linked to the drawing file through a path name or a data management document ID.

  • About Manage Raster Images (VBA/ActiveX)

    You can manage raster image name, file name, and file path using the properties of the Raster object.

  • About Modifying Images and Image Boundaries (VBA/ActiveX)

    After an image has been attached to a drawing, you can modify the raster image's properties and its boundary.

  • About Clipping Images (VBA/ActiveX)

    You can define a region of an image for display and plotting by clipping the image.
