To Create a New VBA Project (VBA/ActiveX)

 
 
 

New VBA projects allow you to store and organize custom macros.

  1. On the ribbon, click Manage tab Applications panel (expanded) VBA Manager.
  2. In the VBA Manager, click New.

    A new project will be created with the default name of ACADProject. To change the project's name you must go into the VBA IDE.

You can also create a project file using the VBANEW command.
