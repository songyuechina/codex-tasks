About Purging Named Objects (VBA/ActiveX)

 
 
 

You can purge unused, unreferenced named objects from a drawing at any time during an editing session.

Purging reduces drawing size. You cannot purge objects that are referenced by other objects. For example, a font file might be referenced by a text style. A layer is referenced by the objects on the layer.

To purge a drawing, use the PurgeAll method, as follows: 

ThisDrawing.PurgeAll
