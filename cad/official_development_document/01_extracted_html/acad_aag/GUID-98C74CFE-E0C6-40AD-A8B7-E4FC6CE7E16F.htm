About Creating Objects (VBA/ActiveX)

 
 
 

While there are often several different ways to create the same graphical object in AutoCAD®, ActiveX Automation offers only one creation method per object.

For example, in AutoCAD there are four different ways you can create a circle: (1) by specifying the center and radius, (2) by two points defining the diameter, (3) by three points defining the circumference, or (4) by two tangents and a radius. However, in ActiveX Automation there is only one creation method provided to create a circle, and that method uses the center and radius.

NoteThe VB and VBA methods of creating objects using either CreateObject or Dim with the New keyword can only be used to create the AutoCAD Application object. All other AutoCAD objects must be created using the Add or Add<objectname> method provided in the AutoCAD interface.
