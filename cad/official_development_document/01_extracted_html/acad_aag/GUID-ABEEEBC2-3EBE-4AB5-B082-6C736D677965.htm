About Canceling a Command (VBA/ActiveX)

 
 
 

To make sure you have no previous incomplete commands, use ^C^C in a macro.

This is the same as pressing Esc twice from the keyboard. Although a single ^C cancels most commands, ^C^C is required to return to the Command prompt from a DIM command. Therefore, ^C^C ensures that AutoCAD returns to the Command prompt in most cases.
