About Naming Your Project (VBA/ActiveX)

 
 
 

The project name and the name of the .dvb file where the project is stored are two different values.

You establish the name of the .dvb file the project is stored in when you save the project. The project name is set in the Properties window of the VBA IDE.

If you do not set the project name and file name, AutoCAD automatically assigns the following default names:

Project name: ACADProject

File name: Project.dvb
