ActiveX Automation Basics

 
 
 

Topics in this section

  • About the AutoCAD Object Model (VBA/ActiveX)

    An object is the main building block of the AutoCAD ActiveX interface.

  • About Accessing the Object Hierarchy (VBA/ActiveX)

    Accessing the object hierarchy is easy from within VBA. This is because VBA is running in-process with the current AutoCAD session so there is no additional step needed to connect it to the application.

  • Collection Objects Reference (VBA/ActiveX)

    A Collection object is a predefined object that contains (is a parent object for) all instances of a similar object.

  • About Properties and Methods (VBA/ActiveX)

    Each object has associated properties and methods.

  • About Parent Objects (VBA/ActiveX)

    Each object has a parent object to which it is permanently linked.

  • About Locating the Type Library (VBA/ActiveX)

    The objects, properties, and methods exposed by Automation objects are contained in a type library. A type library is a file or part of a file that describes the type of one or more objects.

  • About Using Variants in Methods and Properties (VBA/ActiveX)

    ActiveX Automation uses variants to pass arrays of data.

  • About Using Other Programming Languages (VBA/ActiveX)

    Most of the ActiveX related topics were written for use with the VBA programming language. To use the code in other programming environments, you must update it for the chosen environment.

  • About Prompting for User Input (VBA/ActiveX)

    The Utility object, which is a child of the Document object, defines the user input methods.
