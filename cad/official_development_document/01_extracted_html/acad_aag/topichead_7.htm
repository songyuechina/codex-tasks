Use Events

 
 
 

Topics in this section

  • About the Events in AutoCAD (VBA/ActiveX)

    AutoCAD supports different events that allow you to monitor changes to the application environment or drawings.

  • About Event Handlers (VBA/ActiveX)

    It is important to remember that events simply provide information on the state or activities taking place within AutoCAD.

  • About Handling Application Level Events (VBA/ActiveX)

    Application level events are not persistent in AutoCAD VBA.

  • About Handling Document Level Events (VBA/ActiveX)

    Document level events are persistent in AutoCAD VBA. That is, they are automatically enabled when a VBA project is loaded.

  • About Handling Object Level Events (VBA/ActiveX)

    The object level event is not persistent in AutoCAD VBA. That is, it is not automatically enabled when a VBA project is loaded.
