About Programming with Objects from Other Applications (VBA/ActiveX)

 
 
 

Now that you have referenced the object library and created a new instance of the application, you can create and manipulate objects in that application.

All the objects, methods, and properties defined by the Object Model are available to you. For example, using the variable declarations from the previous section, the following line of code makes the Excel session visible to the user: 

ExcelAppObj.Visible = TRUE

You should familiarize yourself with the Object Model of the application you are writing code for. You can use the VBA Object Browser or the application's help file to learn about any Object Model you are referencing.
