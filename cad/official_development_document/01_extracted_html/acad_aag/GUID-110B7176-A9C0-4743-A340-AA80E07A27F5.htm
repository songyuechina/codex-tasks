About Using New AutoCAD Features (VBA/ActiveX)

 
 
 

If your Automation project uses a feature that was not in a previous AutoCAD version, you must explicitly declare the AutoCAD interface you are using in the project.

If an Automation project contains explicit declarations of interfaces that are new in a specific version of AutoCAD, do not use that project with earlier versions of AutoCAD.
