1. Test scope

目标：基于已给证据，归纳“当前系统下，任意矩形多段线能作为打印区域”的最低要求，限定 4 条以内，并区分**代码规则**与**实测规则**。

证据范围：
- 代码文件：`print_area_analysis.py`
- 案例结果：
  - `rect_min_req_source`：识别出**闭合**和**未闭合**两个**轴对齐矩形**
  - `rect_rotated_only`：dry-run 结果 `total_jobs = 0`
  - `rect_closed_only`：单张**实打成功**
  - `rect_open_same_size`：单张**实打成功**

验证方式说明：
- **自动化证据**：`print_summary.json` 中的 plan / total_jobs / execution / verification 信息
- **半自动/人工 CAD 验证**：本任务包未提供额外截图、PDF 或 CAD 运行环境，因此只能引用既有“实打成功”结论，不能追加执行

3. Result / blocker

### 归纳出的最低要求（4 条以内）

1. **必须是矩形多段线**。  
   - 类型：**代码规则**  
   - 依据：`print_area_analysis.py` 注释明确写明“打印范围使用‘矩形多段线’表示”。

2. **矩形需为轴对齐，旋转矩形当前不被接受**。  
   - 类型：**实测规则**  
   - 依据：`rect_rotated_only` 的 dry-run `total_jobs = 0`；而 `rect_min_req_source` 可识别闭合与未闭合的轴对齐矩形。

3. **不要求必须闭合；未闭合矩形同样可以作为打印区域**。  
   - 类型：**实测规则**  
   - 依据：`rect_open_same_size` 单张实打成功；`rect_min_req_source` 也识别出未闭合矩形。

4. **矩形识别受动态容差约束（0.0005 × 外包盒短边）**。  
   - 类型：**代码规则**  
   - 依据：`print_area_analysis.py` 注释说明该容差用于矩形识别、去重、包含关系判断。  
   - 含义：即使满足“看起来是矩形”，仍需落在当前算法容差内。

### blocker
- 本任务包**没有提供**：
  - 具体 PDF 输出文件
  - execution / verification 细节（尤其 `rect_closed_only`、`rect_open_same_size` 的完整实打日志内容未展开）
  - 可用 CAD / TArch 运行环境
- 因此本次结论只能到“**基于现有证据的最低要求归纳**”，不能进一步验证：
  - 非轴对齐但接近轴对齐的边界情况
  - 顶点轻微误差是否仍可通过
  - 开口很大时未闭合矩形是否仍被接受

下一步最优验证路径：
- 在可用 CAD 环境下补做 3 组边界案例：**微小旋转角**、**顶点偏差接近容差阈值**、**不同开口宽度的未闭合矩形**，以把“最低要求”从经验结论提升为稳定规则。
