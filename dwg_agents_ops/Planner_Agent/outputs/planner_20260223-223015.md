太好了，先把“工程图纸基础服务系统”的 MVP 收敛到三件事：插图签（图框/标题栏）、编目录（图纸目录表）、打印（批量出PDF）。下面是可落地的技术路线与3-4周实施计划，请你确认版本与资产后我细化WBS与第一周清单。

目标与范围
- 插图签：按规范在每个布局插入标准图框/图签块，自动填充属性（项目/专业/楼栋/图名/图号/阶段/版次/设计/校对/日期等）。
- 编目录：从布局/图签属性汇总生成目录表（在“目录”布局或模型空间放置表格块），支持刷新。
- 打印出图：按版式(A4/A3/A2/A1)、CTB、PC3 批量出PDF，命名规则可配置（如 项目-专业-图号-图名-版次.pdf）。

技术路线（本地PC、天正CAD环境）
- CAD宿主：优先 AutoCAD(+天正) .NET 插件；如是 ZWCAD(+天正) 则使用 ZRX .NET 插件，接口基本一致（QtZcad）。
- 插件语言：C# .NET（AutoCAD/ZWCAD .NET API + COM），提供稳定命令，UI先从命令行交互开始。
- 外层编排：可选提供一个 Python/CLI（调用 CAD 的 COM `/b` 脚本）做批处理，不依赖UI，提高一次性出图效率。
- 数据源：Excel/CSV（图纸清单）+ YAML（全局配置与映射）。图签属性与字段名做一层映射，便于不同图框复用。
- 兼容天正：不依赖天正自定义对象，只操作布局、块、属性、外部参照与打印，保障跨版本与稳定性。

目录结构与配置（建议）
- 项目根
  - config.yml（全局：出图目录、CTB/PC3、图签块名、字段映射、命名规则）
  - sheets.xlsx（图纸清单：layout、sheet_no、title、size、scale、discipline、building、revision…）
  - blocks/TitleBlocks.dwg（标准图框/图签块库，含A4/A3/A2/A1）
  - plot/CTB/*.ctb、plot/PC3/*.pc3（项目指定样式与设备）
示例 config.yml
```yaml
project: XX项目
discipline: 建施
plot:
  pc3: "DWG To PDF.pc3"
  ctb: "A1_Arch.ctb"
  output_dir: "./_out/pdf"
  naming: "{project}-{discipline}-{sheet_no}-{title}-{rev}.pdf"
titleblock:
  block_name_map:
    A1: "TB_A1"
    A2: "TB_A2"
    A3: "TB_A3"
  attr_map:
    project: "PRJ"
    discipline: "DISC"
    sheet_no: "SHEET_NO"
    title: "TITLE"
    building: "BLDG"
    floor: "FLOOR"
    designer: "DESIGNER"
    checker: "CHECKER"
    reviewer: "REVIEWER"
    date: "DATE"
    rev: "REV"
table:
  index_layout: "目录"
  columns: ["sheet_no","title","size","scale","rev","remark"]
```

插件命令设计（首批）
- TZINSIGN：当前布局按 config/sheets 插入图框图签块，自动对齐页面范围并填充属性。
- TZUPDATTR：批量刷新所选布局的图签属性（从 sheets.xlsx 或当前DWG自定义属性）。
- TZGENDIR：生成/刷新目录表（支持放置点选择、表头样式、列宽自动）。
- TZPLOT：批量出PDF（按布局过滤、纸张映射、命名规则）；支持干跑检查（只生成清单不打印）。
- TZCHECK：体检报告（缺失布局/块、属性未匹配、视口未锁定比例、找不到CTB/PC3、字体缺失）。

关键实现要点
- 布局与幅面识别：优先用 sheets.xlsx 指定 size；否则根据图框块名或布局名规则推断。
- 图签适配：通过 attr_map 解耦字段与块内 AttributeTag，支持不同版本图框共用同一配置。
- 目录来源：以 sheets.xlsx 为准，缺项从图签属性回填；避免人工改动丢失。
- 打印稳定性：强制使用布局出图；设置 PlotView/PlotToFile，避免模型空间比例不一致问题。
- 字体与样式：提前校验 SHX/TTF 是否存在；CTB、线宽与灰度效果以体检报告提示缺失项。
